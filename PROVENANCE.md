# Source and scope

This project is a curated continuation of a recovered personal spectrometer
desktop application. The recovered files were named `Spektrometar.py` and
`driver_test.py`. This repository preserves the main PyQt5/Matplotlib interface
and measurement workflow while separating file/math operations into
`measurements.py` and replacing the acquisition implementation in
`spectrometer_driver.py`.

Preparation added an English interface and documentation, a synthetic offline
demo, worker-thread acquisition, bounded/cancellable serial reads, validation,
portable file handling and automated offline tests. It does not establish the
authorship of every recovered line or claim deployment for a paying client.

The demo curves are generated by formulas in this repository. No recovered
personal measurement files, drivers, executables, build output, virtual
environments, backup archives or undocumented icon assets are included.

Python, NumPy, Matplotlib, PyQt5/Qt and pyserial are external dependencies and
retain their own licenses. They are installed separately; their source/binaries
are not vendored here. No recovered project-code license was found and no new
code license has been assigned during preparation. Code licensing is left for
the repository owner to decide.
